### Doug Leith — Trinity College Dublin

Code and measurement data accompanying my research.
Publications: [scss.tcd.ie/Doug.Leith](https://www.scss.tcd.ie/Doug.Leith/)

---

#### Apple / iOS privacy
- [ios-protobuf-decoding](https://github.com/doug-leith/ios-protobuf-decoding) — recovered `.proto` schemas and an offline decoder for the traffic an iPhone sends to Apple (location services, Maps, Siri, ads, telemetry)
- [ios-location-services-study-data](https://github.com/doug-leith/ios-location-services-study-data) — decoded network traces for *What Location Data Does An iPhone Send To Apple?*
- [poor-privacy-practices-of-the-apple-app-store](https://github.com/doug-leith/poor-privacy-practices-of-the-apple-app-store) — data and software for *Poor Privacy Practices Of The Apple App Store: Cookies, Advertising and Tracking Of Users*

#### Google / Android privacy
- [android-protobuf-decoding](https://github.com/doug-leith/android-protobuf-decoding) — protobuf schemas for decoding Google Play Services traffic
- [cookies-etc-stored-by-google-android](https://github.com/doug-leith/cookies-etc-stored-by-google-android) — data and software for *Cookies, Identifiers and Other Data That Google Silently Stores on Android Handsets*
- [android_OEM_trafficdata](https://github.com/doug-leith/android_OEM_trafficdata) — annotated traffic measurements from Samsung, Xiaomi, Huawei and Realme handsets

#### Measurement tools
- [cydia](https://github.com/doug-leith/cydia) — setting up a Wi-Fi access point and mitmdump to intercept Android and iOS traffic, including bypassing certificate checks
- [appFirewall](https://github.com/doug-leith/appFirewall) — open-source per-application firewall for macOS

#### AI-assisted software development
- [extractor-code-development](https://github.com/doug-leith/extractor-code-development) — reproducibility archive for *Between the Commits: Process, Error, and Claim Reliability in a Wholly AI-Authored Codebase* ([arXiv:2609.29744](https://arxiv.org/abs/2609.29744))
- [claude-python-test-quality](https://github.com/doug-leith/claude-python-test-quality) — reproducibility archive for *The Quality of Claude AI-authored Python Tests Is Not Weaker Than Human-authored Tests* ([arXiv:2608.15188](https://arxiv.org/abs/2608.15188))

#### COVID-19 contact tracing (2020)
- [BLEapp](https://github.com/doug-leith/BLEapp) — Bluetooth contact-tracing study app (Android)
- [GAENLogger](https://github.com/doug-leith/GAENLogger) — captures Google/Apple Exposure Notification beacon scans without special privileges (Android)
- [googleBLE](https://github.com/doug-leith/googleBLE) — copy of Google's Exposure Notifications reference app
- [dublinbus_gaen_dataset](https://github.com/doug-leith/dublinbus_gaen_dataset) — GAEN attenuation measurements on a Dublin bus
- [dublintram_gaen_dataset](https://github.com/doug-leith/dublintram_gaen_dataset) — GAEN attenuation measurements on a Dublin tram

#### Recommender systems
- [SIGIR_clusterbasedbandit](https://github.com/doug-leith/SIGIR_clusterbasedbandit) — code for *Cluster-Based Bandits: Fast Cold-Start for Recommender System New Users*
- [blc-python](https://github.com/doug-leith/blc-python) — BLC matrix-factorisation recommender ([arXiv:1509.05789](https://arxiv.org/abs/1509.05789))
